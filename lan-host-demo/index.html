LAN hosting demo

This video documents the Android local game host service for Google Play review. It uses two real phones: an A22 hosting over its hotspot and an A31 joining the same game.

The demo shows the host starting a room, a second phone joining, Android's ongoing LAN host notification with its Stop hosting action, and the service stopping. The local test build has Full features enabled so the review flow can be shown without a purchase.
